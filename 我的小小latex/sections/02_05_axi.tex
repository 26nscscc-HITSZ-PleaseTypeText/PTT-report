\subsection{转接桥模块（AXI Line Bridge）}

\texttt{axi\_line\_bridge} 位于 L2 与 SoC AXI4 主口之间，负责 32\,B cache 行与 32 bit AXI 突发之间的协议转换，并为 I/D 两侧提供独立读端口。

主要行为如下：

\begin{itemize}
  \item \textbf{行读}：\texttt{ARLEN}=7（8 拍$\times$32 bit INCR）。桥接每凑满 128 bit 向上游回一拍，一行共 2 拍数据，最后一拍拉高 \texttt{ret\_last}；
  \item \textbf{行写}：上游以 2 拍 128 bit 送入整行，桥接缓冲后以 \texttt{AWLEN}=7 写出；支持 AW/W 通道并行握手；
  \item \textbf{Uncached 单拍}：按真实访问宽度设置 \texttt{arsize}/\texttt{awsize}；设备写必须等待 B 响应完成，保证外设寄存器访问次序；
  \item \textbf{双 outstanding 读}：取指读与数据读使用不同 \texttt{arid}（0/1），R 通道按 \texttt{rid} 分流；
  \item \textbf{写后读序}：任一写尚未收到 B 前，不发起新的 AR，避免 victim 写回后同地址 refill 读到旧数据；
  \item \textbf{行写 B 解耦}：行写数据发完即可继续接收，降低写回气泡。
\end{itemize}

顶层 \texttt{core\_top} 对外呈现标准 AXI4 接口。
